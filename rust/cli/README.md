# connectk-cli

The `connectk` command-line application for the ConnectK engine. It includes the standard 7×6 depth-10 exact opening book through `connectk-core`.

Install from crates.io:

```bash
cargo install connectk-cli
connectk solve
```

See the [ConnectK project README](https://github.com/CallMeAlphabet/ConnectK) for the complete command reference and additional installation options.
