# connectk-core

The Rust engine library for ConnectK. It provides the board model, exact and depth-limited solvers, theory lookups, and automatically discovered exact opening books. The standard 7×6 depth-10 book is shipped in this crate's `assets/` directory.

See the [ConnectK project README](https://github.com/CallMeAlphabet/ConnectK) for build instructions, rules, and examples.
